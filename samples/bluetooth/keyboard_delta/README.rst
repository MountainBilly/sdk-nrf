Bluetooth: Peripheral HIDS keyboard With Delta DFU
###################################

.. contents::
   :local:
   :depth: 2

The Peripheral HIDS keyboard sample demonstrates how to use the :ref:`hids_readme` to implement a keyboard input device that you can connect to your computer.

The sample also shows how to perform LE Secure Connections Out-of-Band pairing using NFC.

.. note::
   |nrf_desktop_HID_ref|

Requirements
************

Must install detools as bellow instruction:

https://noy0908.github.io/delta_dfu_lib/testing.html


Overview
********


How to work?

1. execute 54l_delta_1.bat first
2. execute 54l_delta_2.bat to generate the delta patch file 
3. Run the SMP dful using the patch file
